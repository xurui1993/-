# 多模板核算与任务队列

## 页面与操作

兼职薪资核算页使用同一套上传区、任务表格和所选任务详情。闪购自动可以一次选择多份 `.xlsx` 标准template；闪购手动可以选择多个模板及其资料，或拖入按模板分组的目录。自动模式不提供选择文件夹按钮。

每份模板建立一个独立任务，分别保存模式、城市/账期、范围选项和结果。默认顺序执行，运行中仍可继续添加任务或切换新增任务模式。模式和范围的后续调整只影响新提交。

手动资料按最近的含template目录关联。相同目录、相同城市与账期的多个模板可以使用该目录资料；若同一目录的多个手动模板城市/账期不同，资料归属不明确，只给相关任务报错，要求分目录放资料，不能默默套用同一账单。一个模板有问题不阻止后续任务。

手动核算继续保留原有扣款确认要求：资料准备后该任务显示“待确认扣款”，队列继续处理其他可执行任务；确认后重新进入队列。小象超市保留现有上传及核算要求，不套用风神自动采集。

## 后台与恢复

队列保存在本机 `backend/.local_downloads/payroll_queue.sqlite3`，由后台工作线程执行，离开页面或刷新不会停止任务。所有核算执行在进程内串行，OS实例锁避免同一目录启动第二个队列工作进程。

同一上传提交有唯一request_id。网络响应未确认时，浏览器暂存原提交；刷新后沿用同一编号确认，后端返回原任务，不会新建重复队列。尚未执行的任务可在服务启动后继续；服务中断时正在执行的任务标为中断，不自动重跑未知导出或计算。

队列按共享工作区及当前账户的既有权限访问。停止任务采用原合作式停止机制；移出只隐藏共享列表记录、保留输入与结果，可以在“已移出”恢复。多个已完成任务可批量下载为一个ZIP，每模板一层结果目录，避免ZIP套ZIP。

## 日志与界面

默认只显示所选任务最近五条业务动态，重复等待更新为一条。技术噪音、堆栈和内部路径放入折叠的“详细诊断”，原始排错证据继续保留。明确的警告和错误原因仍显示在业务记录，敏感认证值脱敏。完整业务记录可按需展开。

列表轮询只传所选任务的完整日志及资料详情，其他条目传摘要，避免多模板时重复下载所有任务日志。桌面使用紧凑表格，小屏切换为自适应任务行布局。

没有恢复自动扣款确认、资料下载清单、失败项清单或逐项重试入口。既有历史批次仍可通过任务记录查看、继续或下载，不覆盖原文件。

## 接口

| 请求 | 用途 |
| --- | --- |
| GET `/api/parttime/queue?detail_id=...` | 当前队列及所选详情 |
| POST `/api/parttime/queue` | 上传目录按template建立任务，冻结提交配置 |
| POST `/api/parttime/queue/{id}/stop` | 停止单任务 |
| POST `/api/parttime/queue/{id}/continue` | 手动确认原规则后重新排队 |
| POST `/api/parttime/queue/visibility` | 移出或恢复任务，保留文件 |
| POST `/api/parttime/queue/bundle` | 批量下载已完成任务 |

业务记录、会话、上传目录及队列数据库不进入源码提交或源码包。源码包由当前仓库的打包脚本生成，含提交号、逐文件SHA256，并验证CRC和全新解压。
