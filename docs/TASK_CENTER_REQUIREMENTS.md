# 任务中心与统一下载中台需求文档

版本：V1.0；需求确认日期：2026年11月2日；实施基线：`7ee0826`。

## 一、目标与边界

四个平台资料采集及专项报表从任务中心统一发起，以“选择业务场景 → 配置范围 → 确认创建 → 处理待办 → 成套领取结果”为主流程。解决入口分散、下载项目过多、结果零散的问题。

面向采集、运营和薪资核算人员。复用现有采集、认证、报表与核算服务，不新增平台、定时调度、自动审批或发薪功能。不调整计薪公式和账号权限。

保留业务数据、配置、登录会话、上传资料、系统模板、原始回执及已有结果。移出任务仅整理共享列表，不删除文件。

## 二、页面与新建任务

### 主导航

- 任务中心：默认首页，含新建任务、任务列表、成果下载及已移出记录。
- 薪资核算：保留现有核算工作台及执行策略。
- 价格管理：价格审批及每日价格导出。
- 系统配置：平台连接、扣款规则和模板中心。

风神、蓝橙、商翼、灯塔改为任务来源和筛选条件；专项报表并入新建任务。原有业务入口保留准确的记录定位和范围带入。

### 任务中心

顶部为页面摘要、平台连接及新建任务；主体为任务列表和成果下载两个视图，同用一套任务记录。提供全部、进行中、待我处理、已完成计数，以及搜索、平台、任务类型、创建日期和状态筛选。

计数沿用后台状态口径，按唯一主任务计算；内部资料和附件不得重复计数。进行中与待我处理按现有含义允许交集。创建日期与业务账期明确区分。

任务列为：名称、类型及来源、城市及账期、状态及阶段、创建时间、可用成果与操作。任务列表优先显示需处理任务，其余创建时间倒序；成果视图按创建时间倒序。每行突出一个当前主要操作。

桌面采用紧凑表格，小屏自适应；沿用现有中文字体、按钮、表单及抽屉规范。

### 三步新建抽屉

1. 选择业务场景：资料采集或专项报表，默认展示业务包，自定义入口折叠。
2. 配置处理范围：只显示实际生效的城市、日期、月份和站点选项。业务包资料明细默认折叠；调整后转为自定义任务。
3. 确认并创建：显示资料或报表、真实来源范围及产出说明；确认后定位本次任务。

关闭保留当前会话草稿；未提交不建立后台任务。提交后冻结配置，后续修改仅影响新任务。重复点击或响应不明确时沿用原请求编号；相同范围已有任务时可查看已有任务，或明确重新采集新版本。

常用场景包括闪购月度核算资料、闪购日常监控、蓝橙人事全量、商翼员工档案、灯塔骑手日分析、灯塔配送订单、灯塔骑手档案。现有全部资料可通过自定义入口到达。

自定义采集限定单个平台及后台支持的合法组合。灯塔当前仅支持单项独立导出，不把订单、日分析和档案合为无法执行的组合。

专项报表为骑手支付绑定、异常骑手跟进、异常骑手整理；每次只选择一张目标报表。范围、来源和依赖以后台目录为准，由现有服务关联所需资料，不允许任意混合原始资料及生成表。

全量资料显示“全部城市·当前全量”或真实快照范围，不提供无效日期选项。跨平台报表分别说明各来源范围，不暗示所有资料受相同日期过滤。

## 三、执行、详情与下载

### 任务组织和状态

一个业务目标对应一条主记录，平台导出、下载、校验和报表生成作为内部步骤。原任务与后续处理归集；独立发起的采集任务保持独立。保留原执行编号和文件，不复制一套业务资料。

状态使用中文，区分排队、执行、等待登录、等待验证、部分完成、未完成、中断、停止中、已停止、已完成及未知状态。文件存在不代表任务完成；有可靠总数时显示项数，否则显示当前阶段。薪资“已生成·待复核”不代表财务验收通过。

详情顺序为：任务摘要和下一步、成果文件、阶段和异常原因、来源资料、最近五条业务动态、折叠的完整记录及技术诊断。错误保持可见，认证内容脱敏，长校验码留在内部记录。

### 验证和恢复

- 需要验证码时自动提示，当前任务保持等待；收起不取消，可再次打开。
- 同一验证请求收起后不反复自动弹窗，新请求重新提示；同一时刻只展示一个验证窗口。
- 验证码仅由用户主动发送和输入，成功后继续原任务。
- 页面刷新或离开不停止后台任务。恢复和重试仅使用原服务允许的动作，不重发结果未知的平台请求。
- 停止在安全检查点确认后生效；运行中先停止再移出，支持恢复显示。

### 成果领取

- 单任务以下载结果为主操作，多附件统一打包，也可展开单独领取。
- 批量资料与报表首版最多20个任务，每个任务独立目录，直接放入结果文件，避免ZIP套ZIP和同名覆盖。
- 部分完成可领取已有成果，明确显示缺项；不自动标记完成。
- 历史版本保留独立任务和生成时间，不覆盖旧文件。
- 文件不可用时说明原因；浏览器只提示“已发起下载”，不宣称已保存到电脑。
- 专项报表优先交付成品，来源原件按需领取；资料采集领取所选原始资料。其他模块及历史清单规则沿用现状。
- 薪资批量下载使用原核算队列，价格结果沿用原领取方式；不跨业务类型混包，不静默跳过不支持的选中项。

### 薪资兼容

本次只整合薪资任务进度、结果入口及准确返回批次。以 `PAYROLL_TWO_STEP.md` 的当前策略为准，不新增扣款确认、补传、资料清单或失败项重试流程。

保留骑手信息优先导出、验证码等待及验证成功后继续。未完成规定的验证及对应导出不得绕过限制生成工资表。新核算仅交付工资表及蓝橙无单价&未绑名单两份Excel；中文复核清单仍在工资表内，历史结果沿用原规则。

## 四、接口与实施

- 在现有下载选项接口增加业务场景目录，提供稳定标识、名称、平台、说明和合法资料组合。
- 新采集请求可携带场景及来源平台；后台校验同平台和完整组合，并保存可信场景名称。旧请求不添加新字段，不改变原请求指纹。
- 原执行记录增加场景展示元数据，主记录引用原任务及后续处理编号；不另建执行队列。
- 任务中心增加成果视图过滤，筛选在分页及计数前执行；指定历史编号不受当前页限制。
- 列表只读取摘要，所选任务按需加载完整执行记录；验证、停止、继续及下载调用原接口。
- 批量领取流式读取已校验结果，按任务目录直接写入总包，不在业务目录解压或覆盖文件。

先完成入口、页面和三步创建，再完成归集、计数、异常衔接及批量目录；两阶段均属于本次完整交付。上线前检查活动任务，不能强制中断业务；保留布局回退能力。

## 五、验收标准

| 编号 | 验收场景 | 通过标准 |
| --- | --- | --- |
| AC01 | 默认入口 | 默认进入任务中心，四个平台及专项报表均可新建 |
| AC02 | 能力覆盖 | 原有合法下载项目均保留入口 |
| AC03 | 场景创建 | 常用业务三步内创建，依赖由服务关联 |
| AC04 | 范围准确 | 全量、快照、日期、月份和站点选项与后台一致 |
| AC05 | 任务归集 | 一次业务一条主记录，后续处理及内部步骤不重复计数 |
| AC06 | 幂等 | 重复点击、响应丢失和刷新不重复创建 |
| AC07 | 验证闭环 | 自动提示、收起等待、再次打开和成功后继续可用 |
| AC08 | 状态真实 | 部分、失败、中断、未知状态不冒充成功 |
| AC09 | 下载归集 | 单任务成套领取，批量按任务分目录，无ZIP套ZIP和覆盖 |
| AC10 | 薪资兼容 | 当前核算策略及验证要求保留，新结果仅两份Excel |
| AC11 | 历史兼容 | 指定历史任务准确定位，旧资料及旧交付规则保留 |
| AC12 | 停止恢复 | 停止确认后移出，恢复后资料及回执仍在 |
| AC13 | 权限与布局 | 原权限不变，1440、1024、390宽度可操作 |
| AC14 | 数据保留 | 受保护配置、会话、模板及历史资料核对一致 |

回归使用隔离数据及有效ZIP/XLSX夹具。记录真实平台验证的实际范围；模拟检查不代替真实平台下载、审批或工资复核。
